GitHub Pages公開後に全員のスマホをリアルタイム同期します

📌 3ステップでチーム全員のスマホと同期できます（無料）

  1. Firebaseコンソール で無料プロジェクトを作成し、「Firestore Database」と「Authentication（匿名ログイン）」を有効化します。
  2. プロジェクト設定の「ウェブアプリを追加」に表示される firebaseConfig（{ apiKey: "...", ... }）を下に貼り付けて保存します。
  3. 全員共有用のURL（設定埋込済みHTML）を書き出して GitHub Pages にアップすれば完了です！
⚠️「オペレーションに失敗」と出る場合： Firebaseの「Firestore Database ＞ ルール」タブで、認証済みユーザー（匿名ログイン含む）の読み書きが許可されているか確認してください： 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
